# Закрывающий тег

Проектная работа Яндекс Практикума: одностраничный сайт о пути в вёрстке — восемь карточек с CSS-фильтрами, лайками и анимированным сердцем.

Репозиторий: https://github.com/TestSubject-001/zakrivayuschiy-teg-ad

Сайт (GitHub Pages): https://testsubject-001.github.io/zakrivayuschiy-teg-ad/

## Как открыть

Откройте `index.html` в браузере или перейдите по ссылке на GitHub Pages выше. Сервер, установка пакетов и интернет для работы сайта не нужны: изображения, шрифты и иконки сохранены в проекте.

## Что работает

- Восемь резиновых карточек и семь разных CSS-фильтров, включая составной.
- Лайки: по сердцу и по кнопке; текст переключается между Like и Unlike.
- Анимация сердца: заполнение сердцевины и тела, масштабирование и искры.
- Плавная заливка кнопок при наведении и тень при фокусе.
- Модальное окно «Сохранить на память» на элементе `dialog`: закрытие по «ОК».
- Адаптив: резиновые размеры на `clamp`, контрольная точка 375px.

## Структура

- `index.html` — шапка, карточки с инлайновыми SVG-сердцами, символ дискеты и диалог.
- `styles/variables.css` — переменные: шрифты, цвета, ширина контента, градиент фона.
- `styles/globals.css` — базовые стили и утилитарный класс `visually-hidden`.
- `styles/style.css` — раскладка, фильтры, состояния кнопок, адаптивность.
- `styles/animations.css` — переходы и `@keyframes` анимаций сердца.
- `fonts/` — вариативный Inter и Press Start 2P.
- `images/` — иллюстрация карточек и растровые фавиконки.
- `svg/` — векторный фавикон.
- `scripts/like.js` — логика лайков из прекода Практикума.
- `scripts/interactions.js` — открытие диалога «Сохранить на память».
